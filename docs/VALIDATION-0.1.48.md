# Historical validation — 0.1.48

The 0.1.48 validation covered the compiled SDK package, content catalogue, native adapters, transport/interruptions, memory processing, floor-placement corpus and independent model decode. It was an offline validation and did not automate gameplay.

Current 0.1.49 localization checks are documented in [localization validation](LOCALIZATION-0.1.49.md). Exact package hashes belong to the matching build/validation.json report; an older successful report does not validate a rebuilt binary.

## Original research record

The complete original French notebook is preserved in [the historical archive](archive/fr/VALIDATION-0.1.48.md). It records earlier development stages and is not the current user/developer guide. Technical measurements and offsets have not been discarded.
