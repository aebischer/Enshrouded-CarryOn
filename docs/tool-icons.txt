# Tool icon reference and asset history

The transport-pincer item icon uses the game's 200 by 200 tool-icon dimensions, with transparency around the tool and a subdued translucent blue geometric triangular backdrop. The backdrop is intended to match the native hammer/summoning-tool visual language rather than an opaque square.

Prepared assets and their embedding scripts are in the repository. The original notebook retains the source inspection and asset-generation history. Normal builds use the prepared icon and do not need image generation.

## Original research record

The complete original French notebook is preserved in [the historical archive](archive/fr/tool-icons.txt). It records earlier development stages and is not the current user/developer guide. Technical measurements and offsets have not been discarded.
