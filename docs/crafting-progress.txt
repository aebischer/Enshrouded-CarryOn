# Historical crafting integration

The finished tool is crafted manually with one scrap, after the hammer and summoning staff. It uses its own item identity, translated name/description, recipe icon, finished-item icon and held model. It does not retain the hammer's construction blueprint behavior.

The original dated investigation records recipe/resource identity, icon conversion and native text integration. It is retained for engineering traceability, not as current installation instructions. See the README and build/validation guide for the supported build and package layout.
