# Targeting research history

Current targeting requires equipped pincers, active transport mode, focused gameplay and a fresh native target observation. It selects one supported object within reach and respects occlusion. Changing aim, tools, menus or session clears stale selection; hover itself does not move an object.

Chest/decor/interactive policy remains separate from read-only inspection. The inspector may identify unsupported objects without authorizing movement. Highlights and restoration use native render components; component and model identity checks protect against recycled handles.

The linked notebook retains the dated investigation, failed hypotheses and exact native readings that led to the working highlight implementation. Current controls and rendering are documented in [transport interface](INTERFACE-TRANSPORT.md).
