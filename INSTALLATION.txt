CARRYON 0.1.49-dev — WINDOWS X64
Development build — no compiler required for the release ZIP

REQUIRES: Enshrouded ModLoader 0.6.10+ (tested with 0.6.11).
https://github.com/aebischer/Enshrouded-ModLoader/releases
Install the loader first using its INSTALLATION.txt.

1. Close Enshrouded and back up your saves.
2. Extract the complete CarryOn ZIP.
3. In Steam: Enshrouded -> Properties -> Installed Files -> Browse.
4. Merge the supplied Mods directory into the game directory beside
   enshrouded.exe. Do not delete other mods or create Mods/Mods.
5. For updates, back up and replace only the two CarryOn files below:

Enshrouded/
  enshrouded.exe
  dinput8.dll                    supplied by the loader, not CarryOn
  Mods/
    carryon/
      carryon.dll
      carryon.dll.mod

No separate model, texture or translation files are needed. They are embedded
in the DLL/manifest. Do not rename these files or place them under ModLoader.

6. Start the game -> Edit world -> MODS -> CarryOn -> Enable.
   Configure Chests, Decor, Usable objects and Debug for that world.
7. Craft Transport pincers with one scrap in manual crafting, after the
   construction hammer and summoning staff. Equip them, enter transport mode
   (Tab by default), select an object, Pick up, adjust and Place.

Native controls provide preview, positioning, rotation and snapping. Opening
the map during pickup suspends the preview; teleport to another authorized
claim, then resume and place. The original object moves only after validation.
Compatible chests retain contents, decor retains comfort, and supported doors
and wells retain their native state. Unsupported objects are refused.

Keep ModLoader/worlds with your world saves. Settings are per-world and remain
when disabling the mod. Modified loaded settings/mod selection may require
fully restarting the game. Replace DLLs only with the game closed.

Supported enshrouded.exe SHA-256:

Solo use; multiplayer/dedicated servers are not certified. Offline tests pass,
but do not certify every object or replace in-game testing of recent changes.

All 15 game interface languages are included. Documentation uses English.
Use SHA256SUMS.txt and Get-FileHash to verify release contents.
